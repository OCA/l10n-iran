This module provides the **Iranian Chart of Accounts** for Odoo 19.0,
including:

- **385 account templates** organized in 72 account groups (all in Persian)
- **VAT 10%** tax configuration (sale and purchase)
- **Iranian fiscal position** with auto-apply
- **IRR currency** (Iranian Rial) with symbol ریال
- **23 Iranian banks** pre-configured
- **Default property accounts** for receivable, payable, income, expense,
  currency exchange, POS, and cash differences

Installation
============

To install this module, you need to:

#. Clone the OCA/l10n-iran repository
#. Add the repository path to your Odoo addons path
#. Install the ``l10n_ir_account`` module from the Apps menu

Configuration
=============

After installation:

#. Go to **Invoicing > Configuration > Settings**
#. Verify that the **Iranian Chart of Accounts** is selected
#. The chart is automatically loaded as the default for Iran (``base.ir``)
