This module provides **Iranian provinces and cities** for Odoo 19.0,
including:

- **31 provinces** (states) of Iran
- **1103 cities** mapped to their respective provinces
- **State-required** enforcement for Iranian addresses
- **City enforcement** (enforce_cities) for Iran

Installation
============

To install this module, you need to:

#. Install the ``base_address_extended`` module from OCA/partner-contact
#. Clone the OCA/l10n-iran repository
#. Add the repository path to your Odoo addons path
#. Install the ``l10n_ir_states`` module from the Apps menu
